# Simple Note Manager

## Overview

Simple Note Manager is a console-based application written in Kotlin that allows users to create, view, edit, and delete notes.

The purpose of this software is to learn and demonstrate the fundamental concepts of the Kotlin programming language, including variables, expressions, conditionals, loops, functions, classes, data classes, collections, and the use of the `when` statement.

This project was developed as part of the CSE 310 course to explore Kotlin programming and object-oriented design principles.

## Features

- Create notes
- View saved notes
- Edit existing notes
- Delete notes with confirmation
- Input validation for note titles
